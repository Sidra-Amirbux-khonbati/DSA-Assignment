## 📚 Project Overview
This repository contains **Java implementations of core Data Structures & Algorithms**:  
- **Doubly Linked List (DLL)**  
- **Queue (Array & Linked List)**  
- **Searching Algorithms**  
- **Recursion Problems**  
- **Sorting Algorithms (Merge Sort & Quick Sort)**  
- **Binary Search Tree (BST)**  

✅ Implemented **from scratch** (no Java built-in collections used).  
✅ Handles **edge cases** and **includes time/space complexities**.  


## 🏷 Features & Complexity

### 1️⃣ Doubly Linked List
- Insert, Delete (first/last/by value/before/after), Forward & Backward traversal  
- Find Min & Max  

**Time Complexity:**  
- Insert/Delete (first/last) → O(1)  
- Delete by value/before/after → O(n)  
- Find Min/Max → O(n)  


### 2️⃣ Queue
**Array-based & Linked List-based**  
- Enqueue, Dequeue, Peek, Display, Find Min/Max  

**Time Complexity:**  
| Operation | Array Queue | Linked List Queue |
|-----------|------------|----------------|
| Enqueue | O(1) avg, O(n) if resize | O(1) |
| Dequeue | O(1) | O(1) |
| Peek | O(1) | O(1) |
| Find Min/Max | O(n) | O(n) |


### 3️⃣ Searching Algorithms
- Iterative & Recursive Binary Search  
- Recursive Linear Search  
- Recursive Min/Max  

**Notes:** Binary search requires **sorted data** for correct operation.  

**Time & Space Complexity (Recursive):**  
- Recursive Binary Search → O(log n) / O(log n)  
- Recursive Linear Search → O(n) / O(n)  
- Recursive Min/Max → O(n) / O(n)  


### 4️⃣ Recursion Problems
- Factorial, Fibonacci, Sum of Array, Check Sorted, Min/Max  
- **Base case and recursive case** clearly defined  


### 5️⃣ Sorting Algorithms
- **Merge Sort** → O(n log n) / O(n), Stable  
- **Quick Sort** → O(n log n) avg, O(n²) worst / O(log n) recursion stack, Not Stable  


### 6️⃣ Binary Search Tree (BST)
- Insert, Search, Delete, Traversals (Inorder, Preorder, Postorder)  
- Find Min/Max, Count Total & Leaf Nodes, Height  

**Time Complexity:**  
| Operation | Average | Worst |
|-----------|---------|-------|
| Search/Insert/Delete | O(log n) | O(n) |
| Find Min/Max | O(log n) | O(n) |
| Count Nodes / Height | O(n) | O(n) |
